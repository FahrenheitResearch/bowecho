# BowEcho v0.25.5

This release focuses on live-warning reliability, frame-accurate radar loops,
and one-click dual-pol case review packs.

## Highlights

- Added the first five built-in dual-pol data packs:
  Moore EF5, El Reno Wedge, Rochelle-Fairdale EF4, Mayfield EF4, and Rolling
  Fork EF4.
- Data packs now load the needed Level II archive frames, apply the review
  scene, and support quick `-3` / `+3` scan expansion after a pack is loaded.
- Live warnings now stay in live/current mode unless the archive warning sync
  controls explicitly request an archive window.
- Live active-alert refresh now uses the authoritative NWS active-alert
  response immediately and polls on a 30-second cadence.
- Warning labels and sorting preserve stronger current tags such as observed
  tornadoes and PDS tornado damage-threat metadata.
- Unified Player warning auto-sync is now opt-in and labeled as archive sync.
- Live low-tilt refresh now has a configurable auto-advance interval, with
  support for short intervals when operators want faster fresh low-level cuts.
- Manual tilt selection no longer snaps back to the first same-elevation cut
  when a newer low-level cut is selected.
- High-speed screen playback now waits for the selected native-resolution
  texture to be visible before starting that frame's dwell time, so visible
  frames are not silently skipped.
- Synced two-panel playback waits for participating panes to render their
  matching textures before advancing together.
- `VEL` now displays raw radar velocity by default. Use `DVEL` and `DSRV` for
  explicitly dealiased velocity products, or enable `Auto-dealias VEL` when
  that behavior is desired.

## Release Packaging

- GitHub releases now use checked-in release notes when
  `docs/releases/<tag>.md` exists.
- Tagged releases are created as drafts and published only after all matrix
  assets upload successfully.
- Windows signing now runs only when all Azure Trusted Signing secrets are
  configured.
- macOS signing and notarization now run only when the Developer ID certificate
  and App Store Connect notarization secrets are configured.
- Release assets continue to ship with matching SHA-256 checksum files.
