# BowEcho v0.25.6

This release focuses on European severe-weather workflows, coordinated
multi-radar loops, and more trustworthy velocity analysis.

## Highlights

- Added ESTOFEX multi-issue support for Europe, including selectable issue
  times, valid-time awareness, malformed-feed tolerance, official ESTOFEX
  colors, and polygon hole handling.
- Added a Radar Coverage Explorer under Data, with provider/site selection,
  Live / Loop / Archive capability badges, metadata-only probing, direct
  `Use live` and `Load loop` actions, and expandable provider capability rows.
- Expanded Sweden / SMHI support: recent loops now walk SMHI's dated
  year/month/day `qcvol` tree instead of relying only on `lastFiles`.
- Added SMHI archive controls for loading a selected UTC hour or day from the
  Radar Coverage Explorer.
- Broadened ORD historical archive lookup so countries with better native live
  providers, including Sweden, can still be used for direct historical archive
  probing when ORD has older files.
- Added a shared international provider capability catalog so BowEcho can show
  what each network supports now, what the upstream data source likely offers,
  and which archive paths are still future work.
- Renamed `Sync 5` to `Mosaic 5` and tightened coordinated loop playback so up
  to five radar sites can follow one unified timeline.
- Coordinated radar overlays now use timeline-owned playback, selecting the
  latest scan at or before the master timeline time and clearing stale overlays
  instead of leaving final-frame ghosts.
- Low-sweep playback now supports `all low`, `same level`, and `base only`
  modes, with coordinated panes matching physical low-sweep cuts instead of
  copied cut indices.
- Camera-follow playback now interpolates smoothly between track positions
  instead of snapping scan-to-scan.
- Added a hybrid 3-D + temporal velocity dealias engine that can use the
  previous volume, nearby velocity tilts, and range-band wind fits while
  preserving native gate coverage.
- Added a KCRI Latest 20 research-feed data pack and a KVWX velocity-fold QA
  pack for quick review of nonstandard feeds and hybrid dealias behavior.

## Fixes

- Fixed ESTOFEX refresh/parsing cases where current European outlook polygons
  could fail to appear or remain tied to the wrong displayed time.
- Fixed multi-site loop overlay sync so mosaic panes do not freeze on stale
  scans, show future data early, or hold one-frame overlays forever.
- Improved screen/loop playback synchronization so visible coordinated panes
  wait for their matching native-resolution textures before advancing.
- Improved research and custom US radar feed behavior, including Norman
  test-bed style feeds such as KCRI, so nonstandard live feeds advance frames
  more reliably.
- Added regression coverage around coordinated loops, low-sweep filters,
  smooth camera follow, ESTOFEX issue selection, SMHI archive parsing, and
  hybrid velocity dealiasing.

## Notes

- The new Radar Coverage Explorer is a discovery and loading surface, not a
  promise that every national provider has deep archive support yet. Capability
  rows intentionally show what BowEcho can load today versus what the upstream
  source likely makes possible later.
- Full automatic radar handoff/planner mode remains separate future work.
