# BowEcho v0.25.7

This release sharpens two event-room workflows: 3D volume inspection and fast
alert triage.

## Highlights

- Added a Floor PPI option to the 3D Volume Explorer, painting the lowest
  usable reflectivity sweep onto the floor of the 3D box.
- Added a 3D floor alpha control so operators can tune the floor underlay
  without changing the volume-render opacity.
- The 3D floor uses BowEcho's active reflectivity color table and clears stale
  floor textures when a floor raster cannot be built.
- Current alerts now have a Type filter: All, TOR, SVR, Flash flood, Flood,
  Marine, Snow squall, Watch, MD, SPS, and Reports.
- Current alerts now have a Sort control: Priority, Category, Newest, Oldest,
  and Expires.
- Alert type and sort preferences persist in `config.json`, so workflows such
  as `TOR` + `Newest` survive relaunches.
- Added separate hazard-style escalation keys for considerable/destructive
  severe thunderstorm warnings and considerable/catastrophic flood families.

## Fixes And Polish

- Refined the Unified Player radar-source controls: `Add/sync` now makes it
  clearer that loaded loops will sync overlays automatically, and `Nearest 4`
  fills/syncs nearby WSR-88D overlay sites.
- Timeline-synced radar overlays retain their last visible texture while the
  next loop texture renders, reducing one-frame blanking/flicker.
- Renamed the low-sweep filter label from `same level` to `same degree` to make
  the matching behavior clearer.
