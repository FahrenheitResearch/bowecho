# BowEcho v0.25.8

This release is a focused 3D Volume Explorer update: better storm-scale 3D
boxes, safer live-volume handling, and a new fly camera for inspecting storm
structure from inside and around the volume.

## Highlights

- Added `View -> Fly` mode in the 3D Volume Explorer.
- Fly mode controls:
  - drag to look
  - `W` / `A` / `S` / `D` to move
  - `Q` / `E` for vertical movement
  - mouse wheel to dolly
  - `Shift` for faster movement
- Orbit remains the default 3D camera mode.
- Added map-box 3D selection so users can draw/select a storm-scale 3D box
  from the radar map instead of only using the current map center.
- The Volume Explorer is now product-aware, so the selected 3D product and
  active color table drive the 3D volume/floor rendering path.
- 3D controls now use inline panels, avoiding combo boxes closing immediately
  while tuning the volume/floor view.

## Fixes

- Fixed vertical exaggeration for selected/small storm-cell 3D boxes by
  removing the overly low effective height cap.
- Orbit camera now auto-backs out for very tall exaggerated boxes so it does
  not start inside or clipped through the volume.
- Fixed the 3D floor projection so the lowest sweep lines up with the selected
  3D box footprint.
- Added a live-partial guard: the 3D Volume Explorer uses a complete same-site
  volume or waits, instead of resampling from an incomplete live partial volume.
- Improved 3D CPU/GPU projection consistency so annotation and floor alignment
  stay stable across aspect ratios.

## Notes

- This does not add massive multi-radar 3D compositing yet. The current 3D
  renderer still uploads one Cartesian 3D texture from one radar volume; a true
  multi-radar 3D view needs a real composite grid and quality rules first.
