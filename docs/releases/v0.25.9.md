# BowEcho v0.25.9

This release is a quality and workflow pass after the 3D Volume Explorer work:
cleaner archive/event loops, less pane flashing, better search/labels, safer
satellite switching, and a new Brand Kit surface for customized builds.

## Highlights

- Added an App Identity / Brand Kit settings surface for display name, links,
  palette, optional assets, screenshot/loop filename prefix, output folder, and
  optional capture watermark/share-card overlays.
- Added a neutral Generic branded app preset while keeping BowEcho as the
  default identity.
- Unified event/archive tornado workflows so Archive tornado fetches also pin
  the Event Day track layer and show the EF-colored track lines.
- Archive tornado/report clicks now trigger the auto model-hour load path used
  by Event Day track clicks.
- Auto model hour now defaults on for fresh settings.
- Event-track arrows now color by EF rating and expose more tornado details,
  including estimated EF-scale wind ranges.
- Event-track camera follow now extrapolates slightly after lift so post-event
  archive frames do not immediately lose the followed storm.
- Product switching now preserves the current tilt when valid and otherwise
  falls back to the lowest usable tilt for the selected product.
- Added KDP / Specific Differential Phase to the product registry when decoded
  radar data contains it.
- Added radar ID search and improved small-town search.

## Map And Display Polish

- Restored US state-name drawing.
- Improved faint small-town label contrast.
- Improved SPC outlook visibility with stronger fill and better label
  placement.
- Fullscreen / Map Only mode now has a top-hover `Show UI` affordance so users
  can recover tabs and floating windows without feeling trapped.
- Volume Explorer windows and controls are bounded more safely so the broader
  3D UI is harder to lose off-screen or resize into unusable states.

## Playback And Data Fixes

- During loop playback, panes keep painting the previous same-site texture while
  the next exact product/frame texture renders.
- The playback readiness gate still waits for the matching new texture before
  starting that frame's dwell time, reducing REF/VEL/RHO/ZDR flashing in dual
  and quad pane loops.
- Satellite source/sector/layer changes now clear stale frames and ignore late
  frames from the previous satellite selection.
- Unified Player event/archive loading labels now distinguish manual picker
  workflows from track/report loop workflows.

## Notes

- This release does not claim to solve mesoanalysis composites, Skew-T follow
  lag, data-pack lag, or the model timeline UI yet.
- Survey/event track alignment still depends on the source track geometry;
  BowEcho draws the available surveyed/event geometry rather than deriving a
  tornado path from radar.
