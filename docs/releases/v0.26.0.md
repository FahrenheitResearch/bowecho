# BowEcho v0.26.0

This release is a workflow-hardening release after the v0.25 3D/player work:
cleaner tilt behavior, safer live partial panes, better 3D product switching,
product-aware 3D defaults, clearer tornado-track colors, and a refreshed in-app
Guide that now documents the current app instead of the older workflow.

## Highlights

- Added `Restore last tilt per product`, enabled by default.
- Each product now remembers its own selected tilt during the session, so
  switching REF / VEL / CC / ZDR no longer feels like the app forgot what you
  were inspecting.
- Switching to a product for the first time starts on that product's lowest
  available tilt, while clicking or hotkeying the already-selected product no
  longer moves the tilt.
- Keyboard tilt changes now count as explicit manual tilt intent, matching the
  behavior of clicking a tilt row.
- Live low-sweep auto-advance now stays in the same low-elevation family
  instead of jumping from a base low sweep to a newer but higher low tilt.
- `Same level` low-sweep wording was clarified to `Dominant low level`, with
  related labels updated to `In-scan low sweeps` and `Lowest level only`.
- TDWR / terminal-radar completeness checks now treat 360-radial sites
  case-insensitively, improving Txxx behavior.

## 3D Volume Explorer

- Fixed 3D product switching where changing from REF to VEL or another product
  could leave the volume blank until restart.
- The 3D resample/cache key now includes the actual source volume pointer, so
  replaced live/partial volumes retrigger correctly.
- Product changes now fully invalidate stale 3D resample/cache state, reset the
  vertical completeness gate, and clear stale textures.
- Added a no-product-data wait path instead of leaving blank or stale 3D output.
- Tuned 3D defaults by product so velocity and other non-reflectivity products
  are less pillar-like and start with more useful thresholds/opacity behavior.
- Fixed Fly mode mouse Y so looking up/down follows expected mouse direction.

## Map, Labels, And Event Tracks

- Fullscreen / Map Only window picker no longer disappears immediately while
  moving into the Windows menu.
- Small-town labels and state names now use brighter white text with stronger
  halos for better map readability.
- Tornado track colors now use the clearer EF palette:
  EF-U gray, EF0 blue, EF1 green, EF2 yellow, EF3 orange, EF4 red, EF5 purple.
- Event-track colors now use the whole-track EF rating consistently.
- Added a KDP note when dual-pol data exists but the selected frame does not
  actually contain a KDP moment.

## Multi-Pane And Recording Fixes

- Pinned extra panes no longer accept or render fallback cuts when a live
  partial only has a product on a different cut than the pane is pinned to.
- Recorder/playback readiness no longer treats stale or mismatched extra-pane
  textures as ready.
- Extra panes now use the same complete-volume substitution as the primary pane
  for volume-wide products.

## Guide Refresh

- The in-app Guide now documents current BowEcho workflows, including:
  Unified Player, 2000-frame loops, 64x playback, low sweeps, Mosaic 5, camera
  follow, and loop export.
- Added Guide coverage for Radar Coverage Explorer, Data Packs, event/archive
  tornado workflows, auto model-hour loading, GOES GLM, Himawari, MTG caveats,
  3D Floor PPI, Fly mode, screenshots, WebP/GIF/MP4, free record, and Brand Kit.
- Updated source/credit text for international radar providers, ESTOFEX, mPING,
  Spotter Network, RAP/RRFS-style products, GOES GLM, Himawari, and MTG.
- Added guide regression assertions so future edits do not silently drop the new
  Player / 3D / Brand / GLM coverage.

## Notes

- This release does not change the current MTG FCI live-credential limitation:
  discovery/local decode exists, but live European FCI imagery still depends on
  EUMETSAT entitlement.
