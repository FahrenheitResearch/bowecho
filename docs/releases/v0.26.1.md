# BowEcho v0.26.1

This is a focused derived-products and product-switching release on top of
v0.26.0. The goal is to make the new advanced radar products feel like first
class products instead of temporary derived grids: they can be selected,
cycled, recolored, carried across new frames, and used in panes without falling
back into stale or confusing product state.

## Advanced Derived Products

- Added stable advanced-product ordering so PHIF, KDP-derived products,
  velocity-gradient products, and rain-rate products cycle predictably.
- Fixed arrow-key/product-button/hotkey/pane-chip switching so all product
  entry points use the same safe advanced-product path.
- Failed or unavailable advanced products are now skipped while cycling instead
  of trapping the user on an unrenderable product.
- Advanced products now derive on demand when selected, cycled, or hotkeyed.
- Advanced products stay selected across new frames and extra panes when the
  source moments needed to rebuild them are present.
- Low-sweep and product cut lists now consider whether an advanced product can
  be materialized from the frame's source moments, not whether the derived grid
  already exists.
- RATE / RATE_Z / RATE_KDP now display as `in/hr` in Imperial and `mm/h` in
  Metric.
- Unknown advanced products now render with the selected color family instead
  of falling back to Generic coloring.

## Product And Pane Behavior

- Preserved normal REF/VEL tilt memory and lowest-tilt fallback behavior while
  adding advanced-product support.
- Velocity-only UI behavior is now limited to true signed radial velocity
  products, avoiding velocity-specific controls on unrelated derived products.
- Product switching validates advanced materialization before committing the
  selection, which prevents stale panes or blank renders after a new frame
  arrives.

## Derived Math Fixes

- PHIF now survives rejected KDP values instead of disappearing when a KDP gate
  is out of bounds.
- Phase unwrapping no longer bridges long missing-data gaps.
- Hampel filtering now removes spikes even in flat windows with zero MAD.
- VEL_GRAD_R now uses Nyquist-aware wrapped velocity differences.
- KDP/RATE derivation now uses radar-band-aware coefficients when decoded
  frequency metadata is available.

## Decoder Metadata

- CfRadial, ODIM/HDF5, and Dorade readers now extract radar frequency metadata
  where available.
- NetCDF metadata helpers were extended so radar-band-aware derivation can use
  file-level frequency attributes.

## Coordinate Marker Follow-Up

- Coordinate marker search remains available.
- Map-click coordinate marker drops were removed again so normal map clicks do
  not clutter the display.
- Coordinate click markers are now opt-in and safer around derived-product
  workflows.
