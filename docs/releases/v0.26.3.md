# BowEcho v0.26.3

This is a performance and responsiveness release after the v0.26.2 ORD fix.
The main goal is smoother interaction on low-core machines and high-refresh
desktops without reducing native radar resolution or disabling features.

## ORD Dublin / Split-Source Radar Fix

- Fixed Dublin / `iedub` and similar ORD sites where reflectivity and velocity
  are split across different ORD source lanes.
- BowEcho can now build a mixed `SCAN+PVOL` frame, using SCAN as the
  reflectivity anchor and pulling the newest PVOL velocity at or before that
  reflectivity time.
- Mixed frames refuse future velocity, so velocity data cannot appear before
  its real scan time.
- Mixed ORD frames are bounded by age so stale Doppler data cannot silently ride
  along with newer reflectivity.

## Performance

- Tile cache hits are now O(1)-style generation updates instead of scanning and
  touching a linear LRU queue on every texture access.
- Tile texture installs are budgeted per repaint, with deferred repaint when a
  burst has more work than the frame should spend uploading.
- Tile workers are now persistent and sleep on a condition variable instead of
  spawning and exiting during pan/zoom bursts.
- Raster basemap tiles skip expensive mesh/projection work until the tile
  texture exists.
- Tile mesh bounds are computed while building vertices, avoiding an extra
  positions allocation.
- Map label rendering now stops once rank exceeds the active label budget,
  which avoids scanning lower-priority labels that cannot be drawn.
- Radar render workers now reuse conservative viewport geometry caches across
  matching frames/panes before building per-volume sample caches.
- Loop prewarm backs off when visible render/load/3D/model/satellite work is
  already pending, so speculative cache work does not compete with the frame the
  user is trying to see.

## Responsiveness

- Active-load polling, pending-render polling, and loop repaint polling now use
  a 16 ms interactive cadence while work is pending instead of the older 50 ms
  cadence that could feel like a 20 fps UI on high-refresh monitors.
- Explicit `Load Latest` / `Load Loop` clicks now cancel stale in-flight primary
  or pane loads and immediately start the requested load, fixing cases where the
  button needed to be spammed.

## Product Picker Cleanup

- Reverted the temporary KDP/tilt experiment back to stable product behavior.
- Added a `Show derived products` setting so users can hide CREF/ET/VIL and
  computed advanced products from the picker/cycle row when they want a cleaner
  raw-moment workflow.

## Diagnostics

- The performance panel now labels the old frame/FPS metric as repaint cadence,
  which better reflects egui's event-driven repaint behavior.
- Copy diagnostics now include git SHA, dirty flag, build profile, and build
  timestamp.
- Tile diagnostics now show recent processed/uploaded/failed/deferred work and
  timing.

## Release Assets

- GitHub releases now upload direct executable assets alongside the existing
  packaged archives:
  - `bowecho-windows-x64.exe`
  - `bowecho-windows-arm64.exe`
  - `bowecho-linux-x64`
  - `bowecho-linux-arm64`
  - raw macOS command-line binaries next to the signed/notarized app zips
- The zip/tar assets remain available because they preserve README/license
  files, Linux executable permissions, and the macOS `.app` bundle shape.
