# BowEcho v0.27.0

This is a major workflow release focused on the native sounding view,
Italian/international radar data, and layout persistence polish. It also keeps
the v0.26.3 performance work, direct binary release assets, and the Dublin ORD
mixed `SCAN+PVOL` fix.

## Native Sounding View

- Rebuilt the native Sounding view as a SHARPpy-style egui scene instead of the
  old PNG-style rendering path.
- Added Skew-T, hodograph, storm slinky, parcel tables, hover readouts,
  cursor-centered zoom, and draggable/resizable sounding layout regions.
- Added 3CAPE and 6CAPE diagnostics to the sounding parcel table.
- Added configurable sounding overlays:
  - CAPE/CIN fill
  - height markers
  - LCL/LFC/EL level markers
  - wind barbs
  - wet-bulb trace
  - mixed-layer parcel
  - most-unstable parcel
  - DCAPE
- Added trace style controls for sounding overlays: solid, dashed, and dotted.
- Sounding layout, zooms, overlays, and style choices now persist across closing
  and reopening the Sounding pane and across app restarts.
- Sounding no longer forces itself into the bottom dock by default.

## Italy / International Radar Data

- Added Italy DPC gridded radar/composite support using raw GeoTIFF rendering
  instead of zoom-dependent WMTS presentation tiles.
- Added Italy DPC product controls for VMI, SRI, SRT 1h, and multi-hour
  accumulation products with clearer `Accum` labeling.
- Expanded the gridded product catalog for Italy DPC CAPPI, VIL, echo tops,
  probability of hail, IR 10.8, and temperature products.
- Added Italy DPC REST/WMTS planning helpers with stable cache identities that
  ignore expiring signed URLs.
- Added open-data Piemonte and Lombardia radar providers for recent Italian
  volume paths.
- Added global IEM METAR backfill to improve worldwide surface-observation
  coverage.

## Fixes And Polish

- Improved native sounding redraw behavior during point sampling.
- Added persisted settings support for native sounding view state.
- Cleaned up dock behavior so customized layouts are less likely to reset
  unexpectedly.
- Added TIFF/GeoTIFF decode support for the app-side Italy DPC layer.
- Improved surface-observation rendering so global METARs can backfill sparse
  regions without hiding mesonet-style observations.

## Dependency Note

- BowEcho now pins the rusty-weather sounding stack to
  `FahrenheitResearch/rusty-weather@78a473434b60b47a84131562a9ade24c645fe216`,
  which contains the native egui sounding view used by this release.
