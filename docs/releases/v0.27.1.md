# BowEcho v0.27.1

This release follows the native-sounding v0.27.0 release with a broad radar,
grid-layer, model-ingest, and severe-weather workflow pass. The main theme is
making live and experimental data sources more reliable while keeping gridded
overlays visually locked to the map.

## Highlights

- Fixed legacy Level II message type 1 decoding for research/community radar
  feeds such as SWC/KBPP.
- Improved custom/community radar URL handling, including Apache/nginx directory
  listing fallback when a feed does not provide `dir.list`.
- Added Taiwan CWA composite reflectivity support.
- Added shared grid/composite plumbing for MRMS, OPERA/EUMETNET groundwork, and
  app-side raster rendering paths.
- Fixed gridded model/MRMS/satellite overlays drifting, rotating, or stretching
  away from the basemap after map movement.
- Added SPC CIG, SPC fire weather, WPC excessive rainfall, and WPC significant
  river flood outlook support.
- Added affected-zone fallback geometry for NWS watches and alerts that do not
  include inline polygons.
- Expanded Rusty Weather model ingest support and model availability checks.
- Added surface-observation hour-loop/history groundwork and mPING declutter
  guardrails.
- Added Australia NCI radar archive provider groundwork with direct ZIP-member
  ODIM/HDF5 reads.

## Radar

- Decodes legacy NEXRAD Level II message type 1 reflectivity, velocity, and
  spectrum-width moments.
- Restores loading for legacy/research feeds that publish older radial message
  formats.
- Adds ZIP local-member decoding for providers that serve a single archive
  member without a central ZIP directory.
- Adds metadata fallback so sparse community feeds can recover site ID, location,
  and display metadata from surrounding feed context.
- Handles basic web server autoindex pages for feeds that do not expose
  `dir.list`.

Note: K08D is currently listed by the SWC root feed but appears upstream-empty at
release time, so BowEcho cannot load frames until files are published there.

## Model, MRMS, Satellite, And Grid Layers

- Prevents large gridded rasters from being reused in the wrong map projection
  view after pan/zoom changes.
- Improves smoothing/interpolation for model-style gridded overlays.
- Improves default reflectivity coloring for MRMS-like products.
- Adds generic grid composite support for new raster/composite sources.
- Adds Taiwan CWA numeric composite reflectivity ingest/rendering.
- Expands Italy DPC and OPERA/EUMETNET composite groundwork.
- Keeps stale projected textures from stretching into the wrong place while a
  fresh projected render is prepared.

Known tradeoff: model/MRMS/satellite/grid overlays may briefly disappear while
actively panning or zooming, then reappear once the correct projected render is
ready. That is intentional to avoid showing a visually incorrect overlay.

## Outlooks, Alerts, Fire, And Flood

- Adds SPC convective inhibition guidance products.
- Adds SPC fire weather outlook rendering support.
- Adds WPC excessive rainfall and significant river flood outlook support.
- Improves affected-zone geometry fallback for NWS watch/alert products.
- Adds watch/fire hazard styling hooks and default colors.
- Reduces overhead for dense alert and mPING rendering cases.

## Rusty Weather / Models

- Expands ingest-supported model coverage, including HRRR, HRRR-AK, RAP, GFS,
  GDAS, GEFS, AI-GFS, AI-GEFS, HGEFS, ECMWF Open Data, NAM, RRFS-A, REFS, and
  NBM.
- Fixes model availability/latest checks to use fetch-plan aware probes instead
  of hardcoded assumptions.
- Adds forecast-hour normalization for sparse-cadence model products.
- Improves model picker plumbing and field viewer behavior.
- Pins BowEcho's Rusty Weather dependency to
  `FahrenheitResearch/rusty-weather@30bf2702655f82929cc22832c48fa1284d28dbea`.

## Surface Observations

- Improves global METAR/IEM-backed observation handling.
- Adds groundwork for hourly surface-observation loops and station history
  inspection.
- Adds mPING report declutter/budget guardrails with priority-aware retention.

## Color Tables And Styling

- Adds Wilson/AWIPS-style table presets.
- Improves default table selection for reflectivity-like products.
- Adds unit-display work for velocity, spectrum width, echo tops, hail, and
  precipitation-rate style fields.
