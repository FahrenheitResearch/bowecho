# BowEcho v0.27.2

This hotfix tightens live severe-weather refresh behavior, makes
research/community radar feeds easier to use, and fixes a few interaction
rough edges from the v0.27 line.

## Severe / Alerts / MDs

- Fixed SPC mesoscale discussions disappearing and reappearing during live
  hazard refresh.
- Live hazard previews now retain current MD records while final refresh and
  enrichment are still running.
- MD parsing now preserves tornado intensity text such as
  `MOST PROBABLE PEAK TORNADO INTENSITY`.
- Added safer current-live retention so preview refreshes do not temporarily
  wipe valid active MDs.
- Watches and fire-weather polygons are no longer enabled by default, keeping
  the first-run map cleaner.
- Added watch customization style hooks for tornado watches and severe
  thunderstorm watches.
- Added default tornado-watch and severe-thunderstorm-watch colors.
- Improved hazard style threat matching so customized polygon styles apply to
  the correct alert records.
- Fixed ESTOFEX layer draw order so lower categories render underneath higher
  levels.

## Radar / Research Feeds

- Built-in community and research feeds now join the main `SITE` picker.
- KBPP, K08D, KXWA, KCRI, Norman Testbed feeds, and other built-in research
  feeds are selectable directly.
- `Load Latest` on a research feed starts that feed's poll path.
- `Load Loop` on a research feed loads recent frames from that feed's
  `dir.list`.
- Community-feed decoded volumes get metadata fallback for site ID, site name,
  location, and display metadata.
- The right-click radar menu now explicitly groups:
  - normal lowest-beam radars
  - TDWRs
  - research/community feeds
  - custom feeds
  - international radars
- Ctrl-click and automatic closest-radar behavior remain primary/NEXRAD-style
  only, so automatic selection does not jump to research feeds.

## Radar Operational Status

- Right-clicking near a NEXRAD radar now shows NWS radar operational/alarm
  status.
- Radar status fetches are cached and include recent alarm rows where available.

## Vrot / Interaction

- The Vrot tool no longer steals pane dragging/navigation when the user is
  trying to move the map.
- Vrot readouts now respect velocity display units and color-table units more
  consistently, including imperial-style display instead of forcing knots
  everywhere.

## Release Assets

- macOS releases now publish only the signed/notarized `.zip` app bundles, not
  raw bare binaries that can trigger Gatekeeper malware-verification warnings.
- Windows x64 publishes both a raw `.exe` and a `.zip`.
- Windows ARM64 publishes a raw `.exe`.
- Linux publishes raw binaries.
