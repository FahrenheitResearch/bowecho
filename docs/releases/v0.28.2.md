# BowEcho v0.28.2 — The Last Manual Download

Two things ship together: BowEcho can now update itself, and
international radars stop being second-class.

## In-app updates (Windows)

When a new release is out, Settings → security & updates grows an
**Install update** button. One click: BowEcho downloads the exact
variant you are running, verifies the SHA-256 checksum CI published,
verifies the Authenticode code signature through the Windows trust API,
swaps itself, and restarts. Nothing installs without your click, every
failure is shown honestly with the browser flow as fallback, and dev or
rebranded builds never self-update (they keep the releases-page
button). The full verification chain is documented in docs/SIGNING.md.

**This is the last release you download by hand.** From the next one
on, the button does it.

## International radars, first-class

- **The right-click radar menu works everywhere now.** It used to die
  with "No radar within 460 km" across Europe, Australia, and Japan
  while radars sat under the click. International sites now join the
  lowest-beam ranking with real beam heights, and menu picks load into
  the pane you are editing.
- **Ctrl+right-click overlays are back for international radars** (a
  v0.27.2 regression silently added the nearest US radar instead — from
  Europe that meant a WSR-88D across the Atlantic). Nearest US or
  international wins by distance, capped sanely.
- **Real loops on 12 of 13 providers**: DMI (Denmark), GeoSphere
  Austria, CHMI (Czechia), SHMÚ (Slovakia), and DWD (Germany) join the
  loop-capable set — Load Loop pulls real history, oldest first, live
  validated. Japan remains single-frame for now (its archive probing is
  its own project).
- **Honest chrome everywhere**: the LIVE/ARCHIVE chip follows what you
  are actually looking at during international sessions (with a
  cadence-aware staleness floor so slower feeds are not falsely flagged
  stale), the Live checkbox genuinely pauses and resumes international
  polling, and Reset View stays on your session instead of snapping
  back to the last US site.
- **Velocity data trust**: on feeds that carry no Nyquist velocity
  (Japan always, by design), dealiased products now disclose "no
  Nyquist in this feed — showing raw velocity" instead of wearing the
  dealiased label silently.
- The in-app guide was rewritten to describe all of the above and now
  self-tests that the old US-only claims cannot quietly return.
