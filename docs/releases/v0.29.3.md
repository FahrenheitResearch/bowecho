# BowEcho v0.29.3 — Simulated Storms, Sharper Eyes

v0.29.3 turns a WRF run into a radar you can actually scan: point a virtual
NEXRAD at a model supercell and get simulated reflectivity and velocity through
the same loops, color tables, and cross-sections as real Level-II data — proven
against a 250 m tornado-resolving run of the Enderlin EF5. Satellite gets two
major upgrades — native-resolution windowed true color and professional IR
enhancements on true calibrated brightness temperature — warning polygons stop
growing spikes and glow blobs, and a deep stack of audit fixes lands across
tropical, alerts, caches, and performance.

## WRF → simulated radar

- **Scan a model like a radar.** Load a WRF hour and BowEcho builds a synthetic
  radar volume — simulated reflectivity and radial velocity on a real polar VCP
  grid (14 tilts, 720 radials, 250 m gates to 230 km), rendered through the
  exact same pipeline as live Level-II: colormaps, loops, dual pane,
  cross-sections, even GBVTD. Labelled "simulated" so you always know.
- **Sub-cell accuracy.** On a real 2011-04-27 super-outbreak run, the synthetic
  68 dBZ core landed 0.11 km from the model's own composite max.
- **Loop a whole event.** Multi-file WRF loops — pick the tornado hour or the
  derecho hour and scrub it like an archive loop.
- **Place your radar.** Domain center by default, or drop the virtual site at
  any lat/lon or a real NEXRAD id.
- **Clean domain edges.** The thin ring of smeared values at the WRF domain
  boundary is gone — gates outside the true (curvilinear) domain edge are now
  transparent instead of echoing the nearest edge value.
- **Gate texture (opt-in).** An experimental toggle adds deterministic,
  radially-correlated Level-II-style speckle to the simulated gates. Off by
  default — the smooth look you know is unchanged.
- **250 m runs render right.** Fine grids no longer quantize into ~3 km blocks
  (index-resolution fix), and processing streams per-stage progress instead of
  an anonymous spinner.

## Field Loupe

- **Shift-to-magnify.** A GPU-native loupe over any radar moment or model field:
  magnified gates, the value under the cursor, its exact color (with hex), and
  always-on lat/lon. Inspired by Solarpower07's WRF-Runner (thanks!).

## Satellite: crisp where it counts

- **Native-resolution windows.** Point a window (center + size) at a typhoon
  eye and BowEcho fetches only the satellite segments covering it, composing
  true color at the sensor's full 0.5 km instead of the 4× downsampled
  full-sector mush. Successive scans join one run, so the existing loop player
  animates the window with no extra setup. Works for Himawari (segment-level
  fetch) and GOES (windowed decode). Proven live on Super Typhoon Bavi.
- **Himawari full-disk true color.** The H9 True color button now has a scope:
  the west-Pacific region as before, or the WHOLE disk — all ten segments of
  B01/B02/B03 composed into one 2750² (~4 km effective) frame, with a 5500²
  (~2 km) option. A memory-lean strided decode reads only the pixels that end
  up on screen, so the follow thread never touches the 1.9 GB native B03
  plane; scans stack into one loopable `fulldisk` run and land on the map
  through the same baked navigation as every other composite. The native
  window still wins when enabled.
- **Professional IR enhancements.** The classic NESDIS BD (Dvorak) curve —
  plus AVN, Funktop, and rainbow — anchored to absolute brightness temperature
  for both GOES and Himawari, selectable and persisted.
- **Himawari IR is now true Kelvin.** AHI infrared bands are calibrated
  on-device from raw sensor counts (radiance → inverse Planck + band
  correction, per the JMA HSD specification), replacing the old auto-stretch
  approximation — so a 190 K overshooting top reads 190 K, on either
  satellite, and the Dvorak curve means what it says. Frames stored by older
  versions can't be re-calibrated; they keep the legacy auto-stretch and the
  panel says so — load a fresh frame to use the new enhancements.

## Warning polygons: no more spikes and glow

- **Spikes and vanishing fills, fixed.** Complex real-world alert shapes
  (coastline-traced zones, glitched CAP rings) could break the old
  triangulator — painting spike wedges outside the polygon or silently
  dropping the fill at some zoom levels. Fills now tessellate robustly, with
  an exact even-odd fallback for self-intersecting rings; tornado and severe
  warning shapes keep full fidelity.
- **Glow blobs, fixed.** Overlapping warnings of the same type used to stack
  their translucent fills into bright blobs (three stacked severe warnings =
  3× the intended alpha). Same-type fills now flatten to a single paint;
  distinct hazard types still layer intentionally (a tornado warning still
  reads over its severe box).

## Tropical

- **JTWC wind radii.** West-Pacific warnings now draw the authentic JTWC
  graphic: per-quadrant 34/50/64-kt wind roses and the teal gale danger area,
  parsed from the same bulletin we already fetch.
- **NHC storms get radii too.** The Forecast/Advisory's quadrant radii now feed
  the same wind-rose renderer — Atlantic/EPac storms are no longer bare dots.
- **Fresher, truer data.** Forecast geometry refreshes instead of going stale
  on long-lived storms; an NHC outage no longer shows a false "quiet across
  every basin"; the layer is on by default with a closable storm-cards window.

## WRF import you can steer

- **Pick what gets processed.** The full-diagnostics import now has a field
  selector (core-only = 18 fields vs the full 117) with a live count preview.
- **Big grids no longer blow up.** The 800×800×79 full-diagnostics pass peaked
  at 8.9 GB due to an upstream cache that was never cleared — now ~1 GB, with
  per-diagnostic panic isolation so one bad field can't kill the import.

## Branded builds

- **Update checks just work.** A branded build without its own release feed
  now checks the canonical BowEcho releases (and can install updates) instead
  of reporting "not configured." Distributors who point at their own GitHub
  repo or self-host keep their existing behavior.

## Fixes & performance

- **Dealias cache correctness**: cache identity now uses liveness witnesses so
  a recycled allocation can never serve the wrong dealiased grid;
  decoded-volume cache keys include file size+mtime so an overwritten file
  re-decodes.
- **Max REF/VEL swaths off the paint thread** — no more UI hitch as a streamed
  loop rebuilds the swath.
- **Alert watcher stops hammering api.weather.gov** — the background watcher
  reuses the foreground poll instead of re-fetching up to ~320 zone geometries
  every 20 s; an empty-but-valid custom CAP feed is quiet instead of an error
  every poll.
- **Obs history is reachable** — the station timeline no longer requires
  right-click when right-click is bound to radar loads, and Shift+click no
  longer clears the pin.
- **Loupe/inspector color chip** matches the painted color on WRF layers; your
  own color-table edits now beat the built-in Solar palettes.
- **Radar tab layout**: LOOP controls on top, SITE below PRODUCTS/TILT.

## Under the hood

- WRF color tables: unit-aware resolver + 9 Solarpower07 palettes (PW-style
  reflectivity, temp, dewpoint, wind, precip, RH, CAPE, severe, vorticity).
- Crash forensics for large-grid imports documented in
  docs/wrf-import-large-grids.md.
