# BowEcho v0.30.1 — "Simulated Storms, Tuned"

A focused follow-up to v0.30.0: the synthetic-radar-from-WRF renderer gains a
full realism control set, plus two fixes to how simulated and real radar
coexist.

## Synthetic radar: a realism control set

The virtual-radar-from-WRF feature now lets you shape how the simulated scan
looks and behaves, all in the "Virtual radar site & range" panel. Every
setting rebuilds the volume on re-import and is recorded in the run's notes.

- **Reflectivity operator** — choose "Model native (REFL_10CM)", the model's
  own Thompson reflectivity, or "Classic Stoelinga (community look)", the
  fixed-intercept diagnostic the wider WRF/GR2 community's eye is calibrated
  to. The two differ by 10–20 dB in graupel and melting regions, so the
  choice visibly changes core intensity and hook definition on the same frame.
- **Gate texture** — reflectivity now carries realistic pulse-volume texture
  by default (velocity stays clean so dealiasing and GBVTD are unaffected).
- **Ground clutter** — a 0–100% slider adds near-radar ground return with
  range, height, and elevation falloffs and a few hotspots. Storms are never
  overwritten, the pattern is deterministic (loops don't shimmer), and
  cluttered gates read as near-zero velocity like real ground.
- **Realistic Nyquist** — an optional mode that physically folds velocity
  into a chosen Nyquist co-interval (default 25 m/s). Plain velocity then
  aliases the way a real radar measures it, while the dealiased products
  reconstruct the true field — a dealiasing practice ground with known truth.
- **0.1° low tilt** — an optional lowest tilt matching the community scan
  ladder.

## Fixes

- **Simulated radar now displays reliably at startup.** When the app reopened
  with a real NEXRAD site selected, importing a same-named simulated volume
  wouldn't display until you toggled the site off and back. The simulated load
  now takes ownership of the view immediately.
- **No more contention crash importing large WRF while live radar runs.** Live
  radar network decode now pauses for the duration of a WRF/model import (the
  loop keeps playing existing frames and resumes afterward), removing the
  all-core memory pressure that could hard-crash the machine.
