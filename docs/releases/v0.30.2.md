# BowEcho v0.30.2 — "Europe Fixes, Cleaner Core"

A maintenance release: two European radar fixes reported by users, a
responsiveness fix for simulated radar, and the largest internal cleanup in
BowEcho's history — all with no change to how the app looks or behaves for
existing workflows.

## Fixes

- **Romania (ANM) radars now load.** All Romanian sites had been failing every
  poll with a connection timeout on slower network routes to the ANM open-data
  host. The connection timeout was too aggressive for that server; it is now
  tolerant of slow international government hosts. (Users on fast connections
  were unaffected; this rescues everyone else.)
- **Spain (AEMET) velocity no longer shows a "0 mph wall."** AEMET's velocity
  files copy their reflectivity metadata onto the velocity field, so the
  no-data markers didn't match the actual empty gates and most of the velocity
  display collapsed to a solid 0 mph. Empty velocity gates are now correctly
  recognized and masked; real velocity is preserved. No gate filter needed.
- **Simulated radar no longer freezes when switching to Live.** Clicking Live
  from a loaded synthetic-WRF loop briefly froze the app while a large volume
  of simulated frames was released on the UI thread. That cleanup now happens
  off the UI thread — the switch is instant. (This also speeds up switching
  between two real radar sites with large loop histories.)

## Under the hood

The map-painting code — the last large region of the main source file — was
extracted into its own module across four verified, behavior-neutral moves.
`main.rs` is now **63,621 lines, down 19.6%** from the start of the v0.30
series, with every painting, satellite, hazard, and settings concern in its
own file. No behavior changed; the map renders identically.
