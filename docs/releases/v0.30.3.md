# BowEcho v0.30.3 — "Honest Gates"

A small follow-up for the simulated-radar-from-WRF feature, from community
feedback.

## Simulated radar: match gate size to grid resolution

The Virtual radar site panel gains a **"Match gate size to grid resolution"**
option. When enabled, the simulated scan's gate spacing is set to the WRF
file's own grid resolution (its `DX`) instead of a fixed 250 m.

Why it matters: sampling a coarse model at fine radar gates oversamples it — a
3 km grid scanned at 250 m gates produces about a dozen identical gates per
model cell, implying detail the model doesn't actually have. Matching the gate
to the grid makes one gate correspond to roughly one model cell, so the display
is honest about the model's real resolution. On a fine run (e.g. a 250 m
simulation) the result is nearly unchanged.

The gate size is clamped to a sane range (100 m–10 km) and falls back to the
configured value for a file without a grid-resolution attribute. The setting is
recorded in each run's notes, and — like the other simulated-radar controls —
changing it rebuilds the volume on re-import. Off by default; existing runs are
unchanged.
