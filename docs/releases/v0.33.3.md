# BowEcho v0.33.3 — SimSat v0.2.1

BowEcho v0.33.3 updates the first-class **Windows > SimSat** workspace to the
exact public SimSat v0.2.1 release commit
`22dd23b2b956360c53ca6b7b2b445fe76202c392`. This is post-v0.33.2 work; the
already-published v0.33.2 release remains pinned to SimSat v0.2.0.

## SimSat changes

- Surface illumination no longer applies an unintended second limb-darkening
  factor to land, water, or glint.
- Fresh panes and **Recommended** use the reviewed surface-only ground lift of
  1.10. The neutral 1.0 override remains available.
- The pane exposes SimSat's independent twilight terrain recovery, including
  enable, knee, gamma, and maximum-gain controls. Recommended uses
  `0.30 / 0.50 / 4.0`; the effect fades in from -6 to 0 degrees solar
  elevation, remains full through +4, and returns to identity by +12.
- GPU preview now retains both post-light terrain controls. SimSat v0.2.1 uses
  the same post-view formulas on CPU and GPU instead of weakening the preview.
- **CIMSS Style** is the recommended Band-13 presentation. Explicitly entering
  an IR or water-vapor product selects CIMSS and recolors the shared Satellite
  player; startup in the same product still preserves an explicitly saved
  palette. Natural NOAA heritage grayscale remains available.

## Settings compatibility

SimSat pane state advances from schema 2 to schema 3. A saved v0.2.0 payload is
migrated once without changing its rendered appearance: its existing ground
lift is retained and the newly introduced twilight recovery is written as off.
Applying **Recommended** is the deliberate opt-in to the v0.2.1 calibration.
Source paths, jobs, progress, and output remain session-only as before.

Compact production caches remain SSB v6, and ScienceCloudF16 remains isolated
in its v7 cache, so this engine update does not force a compact-cache rebuild.
