# BowEcho v0.34.14-rc.1

This release candidate reconciles the post-v0.34.13 radar, sounding, map,
contour, and 3D-renderer work into one reproducible build. It also restores the
full Classic radar workspace by default while keeping the smaller layout as an
option.

## Radar workspace and customization

- Restores the pre-minimalist Classic radar controls as the default without
  removing the Compact layout or the v0.34.13 progressive archive loading,
  frame status, and typed scrubber.
- Adds a persistent sidebar layout document with versioned migration and
  forward-compatible unknown-section handling.
- Adds user-created sidebar tabs assembled section by section. Tabs can be
  created, renamed, duplicated, reordered, and deleted; their sections can be
  added, removed, and reordered without requiring drag-and-drop.
- Keeps built-in Radar, Map, Alerts, Data, and Settings tabs available while
  allowing custom tabs to collect the operator's most-used controls.

## Radar correctness and performance

- Smooths differential phase as a circular quantity, so values around the
  0/360-degree boundary no longer average through an unrelated angle.
- Centralizes correlation-coefficient and velocity interpolation guards while
  preserving missing-gate coverage and the established scalar smoothing path.
- Keeps RHI and native-beam cross sections on measured dBZ with corrected
  elevation-angle weighting.
- Corrects CfRadial gate-center placement, field/`standard_name` mapping, and
  ray-time epoch rebasing; derived texture fields can no longer impersonate a
  measured moment.
- Bounds CfRadial sweep expansion and HDF5 B-tree depth plus aggregate decoded
  dataset bytes, so malformed radar containers fail instead of exhausting a
  worker stack or process memory.
- Defers expensive same-family warning-fill unions during map interaction, then
  restores the fills when interaction stops.

## Soundings and observation analysis

- Vendors the current `sharprs` engine used by BowEcho and corrects effective
  bulk wind difference and Bunkers-motion handling in the OA composite pass.
- Preserves exact pressure endpoints during height/pressure interpolation so an
  on-level helicity request cannot become out-of-range through floating-point
  roundoff.
- Makes active storm motion and cyclonic-positive helicity hemisphere-aware,
  and aligns missing-effective-inflow composite output with SHARPpy semantics.
- Adds direct SCP, STP, and VTP parity/cutoff coverage and corrects misleading
  effective-inflow and effective-bulk-shear field labels.

## Contours and 3D radar

- Replaces the upper-air contour extraction hot path with the reconciled
  weather-contours implementation and its topology/correctness test suite.
- Adds the positive-energy log-spherical-harmonic lighting renderer, stable
  lighting cache revisions, conservative multilevel empty-space hierarchy,
  segment-preintegrated transfer functions, and advanced 3D support views.
- Keeps floor projections honest by carrying an explicit validity channel;
  missing floor cells no longer appear as valid low-valued data.

This is a release candidate. Operational decisions should continue to use
authoritative radar, observation, warning, and forecast sources while the
combined UI and GPU paths receive final field testing.
