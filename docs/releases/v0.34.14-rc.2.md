# BowEcho v0.34.14-rc.2

This release candidate restores a more practical radar workspace and brings
together the latest radar, sounding, map, contour, and 3D improvements.

## Radar workspace

- The full Classic radar sidebar is the default again. The smaller Compact
  layout is still available.
- You can create custom sidebar tabs and fill them with the controls you use
  most. Custom tabs can be renamed, duplicated, reordered, and deleted, and
  their sections can be added, removed, or reordered.
- **Add sections** now opens correctly, including from an empty custom tab, and
  takes you directly to that tab's editor.

## Radar and maps

- Cursor probes, Vrot measurements, and pinned inspectors now stay tied to the
  exact pane, frame, product, tilt, dealiasing setup, and storm motion shown on
  screen. Changing the source clears stale measurements.
- Radar range edges now line up correctly in map views, RHI displays, swaths,
  and CfRadial import/export.
- Differential phase now smooths correctly across the 0/360-degree boundary.
- Panning stays responsive on warning-heavy maps; warning fills return when
  interaction stops.
- Additional safeguards prevent damaged or hostile radar files from consuming
  unbounded memory or stack space.

## Soundings and objective analysis

- Corrected effective bulk wind difference and Bunkers storm motion in the
  objective-analysis composite fields.
- Improved SCP, STP, VTP, helicity, and effective-inflow behavior, including
  Southern Hemisphere storm-motion handling.
- Fixed pressure-level edge cases that could incorrectly reject an otherwise
  valid sounding calculation.
- Clarified effective-inflow and effective-bulk-shear labels.

## Contours and 3D radar

- Upper-air contours generate substantially faster while preserving line and
  filled-band topology.
- Upgraded 3D lighting and volume rendering make storm structure easier to
  read and reduce unnecessary work in empty parts of the volume.
- 3D thresholds and surfaces now behave appropriately for reflectivity,
  velocity, correlation coefficient, differential reflectivity, KDP, spectrum
  width, and differential phase.
- Maximum Projection now favors the strongest visible contribution, and
  missing velocity or floor data no longer appears as a valid strong return.
